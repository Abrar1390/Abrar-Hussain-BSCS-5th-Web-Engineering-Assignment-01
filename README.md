# Task Management API

## Setup

Install dependencies:

```bash
npm install
```

Create a `.env` file from `.env.example` and set the PostgreSQL credentials.

Ensure PostgreSQL is running, then create the database:

```bash
npm run setup:db
```

## Run

Start the application:

```bash
npm start
```

Start in development mode:

```bash
npm run dev
```

Run tests:

```bash
npm test
```
